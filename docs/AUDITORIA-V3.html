Design System e manutenção

9822 arquivos do snapshot vendor foram comparados e permaneceram idênticos. Os componentes oficiais são renderizados por ilhas React; as adaptações necessárias ficam em src/ds-compat.jsx. O Form também usa controles oficiais. O CSS dos componentes foi isolado para evitar colisão com nomes de blocos nativos. Tipografia e cores semânticas usam os tokens oficiais PF/PJ claro/escuro. Isso não representa certificação visual de cada combinação ou auditoria WCAG completa.

95 blocos, 147 modelos e 2.421 campos editoriais, incluindo condicionais e compatibilidade. Funções e propriedades técnicas recebem adaptação explícita; não são campos de código no editor. As composições respeitam o modelo XWalk, sem aninhamento arbitrário.

Como implantar

  1. Preserve o site e faça backup Git/AEM.
  2. Atualize código, configuração de ambiente e arquivos compilados.
  3. Escolha importar os exemplos ou migrar uma cópia do conteúdo editorial existente; não sobrescreva edições com o showcase completo.
  4. Republique as páginas afetadas para Preview e valide a persistência real no editor.
  5. Após homologar, publique para Live e conecte os serviços reais quando seus contratos forem fornecidos.
