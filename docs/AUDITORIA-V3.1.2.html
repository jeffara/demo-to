O que “100%” pode e não pode significar aqui

100% dos casos executados passaram. Isso não é uma garantia de ausência absoluta de defeitos.

  • 64/64 exports oficiais representados; 751 propriedades próprias classificadas. Não equivale a todos os atributos HTML herdados expostos no editor.
  • Callbacks, slots e referências técnicas têm adaptações: ações/eventos, composição de conteúdo e seletores. Não são todos campos textuais editáveis.
  • Salvar e reabrir conteúdo na instância AEM/Universal Editor autenticada não foi testado nesta revisão.
  • UI nativa do calendário em Safari, Firefox e aparelhos móveis reais permanece para homologação. Os testes observam a geometria na chamada showPicker.
  • Serviços REST reais e credenciais não configurados permanecem fora da homologação. A busca depende de índice publicado.
  • A atualização 3.1.2 ainda precisa ser levada ao GitHub conectado ao seu site.

Colunas no Universal Editor

A Adobe não oferece o Responsive Grid do Page Editor no Universal Editor. O projeto expõe proporções, larguras, colunas, alinhamentos, espaçamentos e ordem móvel nas propriedades. Não existe aqui uma alça nativa para redimensionar colunas por arraste.
