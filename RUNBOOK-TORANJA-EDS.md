# Runbook Toranja EDS

As instruções desta versão estão em [README.md](README.md), [migração AEM](docs/MIGRACAO-AEM.md) e [guia de autoria](authoring-guide.md).

Comandos: `npm run preview`, `npm run build`, `npm run check`, `npm test`.

Os HTMLs locais ficam em `drafts/`. A produção usa páginas AEM. Não substitua o runtime oficial `scripts/aem.js` por um loader próprio nem publique as fixtures como se fossem conteúdo persistido no AEM.
